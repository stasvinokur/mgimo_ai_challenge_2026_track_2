# UI «Пульса»

Все цвета обеих тем, типографика, шаг отступов, радиусы и тени — в `src/app/globals.css` (`@theme` + CSS-переменные). Используйте семантические классы Tailwind: `bg-card`, `text-muted-foreground`, `border-border`, `rounded-xl`, `gap-4`. Golos Text с кириллицей поставляется локально. Новые цвета и размеры сначала оформляйте токенами здесь.

## Примитивы

Импорты — из `@/ui/primitives/<имя>`:

- `Button`: `variant="default|outline|secondary|ghost|destructive|link"`, `size="default|sm|lg|icon"`. Область касания от 44 px. Для ссылки: `<Button asChild><Link href="/requests">Открыть заявки</Link></Button>`. Иконке без текста нужен `aria-label`.
- `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, `CardFooter`: обычная карточка. В `CardTitle` передавайте заголовок нужного уровня, например `<h2>Заявки</h2>`.
- `StatusBadge tone="neutral|info|success|warning|danger"`: обязательный текст в children; цвет дополнен значком. Не используйте бейдж вместо кнопки. Доменные статусы маппит вызывающий лейн.
- `Skeleton`: размер через `className`. Родитель — `aria-busy="true"`, один текст `role="status"`. Пример — `PageLoading`.
- `EmptyState`: `icon` (LucideIcon), `title`, `description` с понятным следующим шагом, `action` (кнопка/ссылка).
- `ErrorState onRetry={reset}`: общее безопасное сообщение и повтор. Не выводите текст исключения, идентификаторы и технические подробности.
- `Sheet`, `SheetTrigger asChild`, `SheetContent`, `SheetHeader`, `SheetTitle`, `SheetDescription`, `SheetClose asChild`: Radix Dialog, по умолчанию нижний лист. Заголовок и описание обязательны; фокус удерживается внутри, Escape закрывает, фокус возвращается к триггеру. Закрытие по-русски, safe-area учтена.
- Тосты: `import { toast } from "sonner"; toast.success("Изменения сохранены")`. `Toaster` уже смонтирован один раз в `Providers`, тема и подписи настроены. Для ошибки, требующей действий, используйте состояние страницы; важную информацию не оставляйте только в исчезающем тосте.
- `cn` из `primitives/utils` объединяет классы. Кнопка, карточка, badge, skeleton, sheet, sonner получены через `pnpm dlx shadcn@latest add …`, адаптированы для русского интерфейса и 44 px; Radix — базовая библиотека. `components.json` направляет генерацию в этот каталог.

## Оболочка и маршруты

Единственный список разделов — `shell/navigation.ts`. `audience` выбирает кабинет, `placement="primary"` — боковую и нижнюю навигацию, `header` — верхнюю кнопку и дополнительный пункт desktop. Состояние определяется URL, вложенный маршрут сохраняет активный пункт. При добавлении раздела меняйте этот список; компоненты панелей менять не нужно. Страницы лейнов получают оболочку из `(student)/layout.tsx` или `(staff)/layout.tsx`.

`page.tsx` заменяйте содержимым своего контекста. `SectionPage` — временный общий макет без учебных данных. `loading.tsx`, `error.tsx`, `not-found.tsx` в каждой route group наследуются всеми её разделами; при необходимости переопределяйте их внутри контекста. Корневые 404/403 также оформлены. Корневой layout получает конкурсный текст через `GetConcept` и выводит один футер на всех страницах.

UI получает данные через props; серверные зависимости и Actor собираются в `src/app`. Оболочка пока открыта: вход и авторизация относятся к TASK-10. Переход между кабинетами — демонстрационная ссылка, её следует заменить при подключении сессий.

## Проверки ревьюера

`pnpm test:e2e` проверяет навигацию на 360/1440, обе темы, сохранение темы, фокус/клавиатуру, sheet, касание, переполнение, локальность запросов и axe. `screenshots.spec.ts` сохраняет 28 PNG: семь страниц × две темы × 360×740/1440×900 в `docs/screenshots/` (без гонки имён между проектами). Перед снимком ожидаются шрифты и тема, анимации отключены. Chromium в песочнице исполнителя не запускается; снимки создаёт ревьюер.

Иконки: `/pulse.svg`, `/favicon.svg`, `/icons/icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`. Maskable-значок имеет сплошной фон и знак в центральной безопасной области. Манифест подключит PWA-лейн M3.
